# Hydraulic Service — Sistema de Gestión de Equipos y Arriendos

Sistema web en desarrollo para mejorar la gestión operativa de Hydraulic Service, empresa dedicada a servicios relacionados con equipos hidráulicos.

El proyecto busca centralizar la información de los equipos, controlar su disponibilidad y facilitar la administración de los procesos de arriendo mediante una plataforma web.

## Objetivo del proyecto

Desarrollar un sistema que permita optimizar los procesos internos de la empresa, reduciendo la dependencia de planillas de cálculo y registros manuales, mejorando la trazabilidad de los equipos y facilitando el acceso a la información.

## Problemática

Actualmente, parte de la información operativa se administra mediante planillas de cálculo y documentos independientes. Esto dificulta consultar rápidamente la disponibilidad de los equipos, mantener sus datos actualizados y gestionar los procesos de arriendo de manera centralizada.

El sistema propone una solución digital para organizar y simplificar estos procesos.

## Funcionalidades previstas

- **Gestión de equipos:** registro y administración de tipos de equipos y sus unidades individuales.
- **Control de disponibilidad:** seguimiento del estado de cada unidad, diferenciando equipos disponibles, arrendados y en taller.
- **Gestión de arriendos:** registro de arriendos y detalle de los equipos asociados.
- **Información técnica:** almacenamiento de códigos internos, números de serie, marcas, modelos y especificaciones.
- **Gestión documental:** proyección de funcionalidades para la generación de contratos de arriendo y la administración de documentación relacionada.

Las funcionalidades se implementarán progresivamente durante el desarrollo del proyecto.

## Tecnologías

- **Framework backend:** Laravel 13
- **Panel de administración:** Filament 5
- **Base de datos:** MySQL
- **Lenguaje principal:** PHP

## Estado del proyecto

En desarrollo. Actualmente se está construyendo la estructura del sistema y sus módulos principales.

## Propósito

Este proyecto forma parte de una iniciativa de mejora de procesos internos de Hydraulic Service y busca aplicar soluciones de desarrollo de software a necesidades operativas reales.
